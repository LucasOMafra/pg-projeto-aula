# 📚 Projetos de Aula - Bloco 1 | JavaScript & TypeScript

Este repositório reúne todos os **projetos, atividades e exercícios** desenvolvidos durante o **primeiro bloco do Bootcamp Fullstack da Generation Brasil**, com foco em **JavaScript** e **TypeScript**.

---

## 🧠 Objetivo
Consolidar o aprendizado dos **fundamentos da programação**, passando pela **lógica, sintaxe e estruturas da linguagem**, até a introdução à **Programação Orientada a Objetos (POO)**. Cada atividade desenvolvida representa um passo na evolução do conhecimento, desde os primeiros conceitos básicos até a construção de programas mais estruturados e orientados a boas práticas de código.


---

## 🧩 Conteúdo Praticado
- 🟨 Fundamentos do **JavaScript**
- 🔷 Introdução ao **TypeScript**
- ⚙️ Estruturas de repetição e condicionais  
- 💾 Manipulação de dados e entrada via terminal  
- 🧱 Programação Orientada a Objetos (POO)
- 🧩 Criação de projetos modulares com Node.js

---

## 🧱 Tecnologias Utilizadas
- 🟨 JavaScript  
- 🔷 TypeScript  
- ⚙️ Node.js  
- 🧰 readline-sync  

---

## 🚀 Estrutura do Repositório
📁 **/projeto-aula**  
Contém os exemplos e exercicios desenvolvidos ao longo do primeiro bloco do curso, como:
- Declaração de variáveis e tipos de dados  
- Operadores aritméticos e lógicos  
- Estruturas condicionais (`if`, `else if`, `switch`)  
- Laços de repetição (`for`, `while`, `do...while`)  
- Arrays e matrizes  
- Funções e escopo  
- Introdução à Programação Orientada a Objetos (POO)  
- Manipulação de dados e interação via terminal
